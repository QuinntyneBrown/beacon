# Beacon Wireframes

Source: `docs/mocks`.

Included final app screens:

- `sign-in` from `login.html`
- `boards-dashboard` from `boards.html`
- `kanban-board` from `board.html`
- `card-detail` from `card.html`
- `settings` from `settings.html`

Excluded mock pages:

- `index.html`: mock launcher / navigation index only.
- `components.html`: design-system reference only, not a final app route.

Viewport conventions used by these wireframes:

- Mobile: under 600px. App screens use top app bar plus bottom navigation. No rail or drawer.
- Tablet: 600px to 1239px. App screens use top app bar plus an 80px navigation rail.
- Desktop: 1240px and wider. App screens use top app bar plus a 256px navigation drawer.
- Auth desktop split starts at 900px: the sign-in page gains a left marketing hero and right form panel.
- Card detail and settings inner two-column layouts start at 900px.

The wireframes are intentionally simple Markdown diagrams, but they preserve screen order, major regions, visible labels, navigation variants, overlay elements, and responsive layout changes from the mocks.
